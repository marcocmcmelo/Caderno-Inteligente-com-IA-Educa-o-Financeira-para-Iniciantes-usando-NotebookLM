# Caderno-Inteligente-com-IA-Educa-o-Financeira-para-Iniciantes-usando-NotebookLM
## Descrição do Projeto

Este projeto demonstra o uso da Inteligência Artificial como ferramenta de aprendizagem ativa por meio da criação de um caderno temático no NotebookLM. O objetivo foi estudar fundamentos de educação financeira para iniciantes através de curadoria de fontes abertas, engenharia de prompts e análise crítica das respostas geradas por IA.

O resultado é um mini guia estruturado contendo resumos, glossário financeiro e uma biblioteca de prompts reutilizáveis para estudo contínuo.

## Objetivos do Projeto

Demonstrar uso prático de IA no aprendizado

Aplicar curadoria de fontes confiáveis

Testar diferentes estratégias de prompts

Produzir material educacional estruturado

Desenvolver pensamento crítico com apoio de IA

## Fontes Utilizadas

Cartilhas da CVM

Materiais do Banco Central

Guia do Investidor — Tesouro Direto

Cartilhas de Educação Financeira institucionais

Material educacional financeiro aberto

## Metodologia

Curadoria de fontes abertas

Organização no NotebookLM

Definição de objetivos de estudo

Criação de perguntas estratégicas

Testes com múltiplas variações de prompts


## Tecnologias

NotebookLM

IA Generativa

Curadoria de Conteúdo
